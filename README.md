# dolbotally

dolbotally is a frankly simplish multi-tally counter. It allows you to make unlimited counters and define add/sub amount and minimum/maximum value for each.

## Installation.
Prerequisites:
- Rust/Cargo installed on your system (preferrably latest possible version)

### Through Cargo (recommended)
```bash
    cargo install --locked dolbotally
```

### From source
```bash
    git clone https://codeberg.org/enmkdev/dolbotally && cd dolbotally && cargo install --path .
```
